What it takes to build

Rough working days. Shorter is cheaper to try and cheaper to undo.

Build effort by concept

Terracotta bars are the two I would start with.

Milanote, specifically

You asked whether it can live inside this. It can, and more fully than I expected.

A real embed, not a link
confirmed against Milanote's own documentation

Milanote lets you turn on a read-only link for any board, and once that is on it will generate an HTML embed code. That means the board can render inside a ConnectHub project page rather than throwing someone into another tab.

Who sets it upWhoever owns the board
What they paste inOne link, once, per project
Comments & reactionsOptional, on by default
EditingStill happens in Milanote

The honest limit: a read-only embed is read-only. Staff would look at the board here and edit it there. There is no Milanote API that would let ConnectHub write to a board, so a true two-way sync is not on the table.

One thing to decide before we build it: a read-only link is public to anyone who has it. That is fine for a Gala moodboard and wrong for anything with student or family detail in it. I would put that warning next to the field rather than in a manual nobody reads.
Meeting times — my answer

You asked whether they belong here. Yes, but as one field, not a calendar.

One next meeting per project
not a scheduling system

A date, a time and a place on the project, shown in the meta line next to the date it already has, and pulled onto the dashboard as "Next: Tuesday 2:00PM". A small button downloads it to Outlook or Google Calendar.

Where it showsProject header + dashboard
CalendarOne-tap .ics download
What it is notInvites, RSVPs, recurrence

Why stop there: the moment it sends invites it is competing with the calendar everyone already lives in, and losing. One field that says when to turn up is the whole job.
